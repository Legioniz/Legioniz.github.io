# TOKI SATSUEI — GitHub Pages site

This is a static photography website served from:

https://legioniz.github.io/toki-satsuei/

## Files
- `index.html` — page structure and editable text
- `styles.css` — visual system and responsive layout
- `site.js` — mobile navigation, gallery filters/lightbox, inquiry-message copier
- `media/` — brand and portfolio images

## Update notes
1. Replace the Facebook search URL in `index.html` with the direct TOKI SATSUEI page URL when available.
2. Update package names/prices and delivery notes in the Session Guide section of `index.html`.
3. Replace or add gallery images in `media/` and update the matching image paths and captions in `index.html`.
4. Keep the site static. The inquiry form copies a message for the visitor to paste into Facebook; it does not send or store form submissions.

## Brand
Keep the site minimal and editorial: black/charcoal, warm white, and restrained crimson; preserve the brushstroke emblem, Japanese subtitle `時の記憶`, and the tagline “CAPTURING MOMENTS, PRESERVING MEMORIES.”
